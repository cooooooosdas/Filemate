# 求职训练中心的数据边界

V2.5 复用现役 SQLite、Artifact、图谱、编程和面试接口。岗位导入及创建训练先在页面展示并确认；不自动抓取网站、不发送岗位文本至外部模型。`extract_requirements` 只是本地公开词表提取，原句和类别须由用户核对。

`catalog.py` 的三个岗位为 2026-10-01 采集的短篇训练摘要。来源是 [百度搜索架构校招页面](https://talent.baidu.com/jobs/detail/GRADUATE/62597167-3972-42ef-98aa-162290f5e7e6)、[百度 AI 研发实习页面](https://talent.baidu.com/jobs/detail/INTERN/46efcb09-9461-4401-925f-8aaf611994d8) 和 [腾讯微信小店后台开发页面](https://careers.tencent.com/zh-cn/jobdesc.html?postId=1936827253514149888)。原页面日期分别为 2026-07-30、2026-07-21、2026-09-28；腾讯岗位要求工作经验，归为社招参考。摘要不是原 JD 全文，不表示仍在招聘、企业合作或企业授权推荐。须打开原页面核对状态。

每项要求的 `evidence` 是本平台保存的岗位摘要或用户导入文本的原句；不能将用户修改后的内容继续标记为平台核对的官方快照。编辑会生成新岗位版本，旧训练仍保存当时的岗位和证据快照。

`evidence.py` 的七道基础题和五道岗位口头训练模板由平台原创；算法训练链接到 V2.3 的原创题。不是企业真题、题库抓取结果或招聘方评分标准。基础题按固定答案计算本轮结果；编程由真实隔离引擎裁决；内容分析复用 V2.4 的逐题外发确认和证据校验。

关联方式为公开标签词表：岗位技能与已确认图谱节点、原创算法分类匹配；需人工核对关联。图谱统计沿用现役最近窗口，不合并成独立作答数。编程只统计全部有效、未撤销的完成提交，展示最近20个引用；不计取消和基础设施失败。基础题统计取该岗位最近100份训练的完成记录，同题可跨轮重复，不构造岗位适配率或能力总分。面试只展示与该岗位关联的实际已答及已评估题数。

没有证据显示“待评测”；未录入不代表不会。当前代码评测仅 C++17，Python/Java 岗位会注明该语言的代码评测尚未支持。项目和表达仍需要人工核对原回答。

删除只影响选定岗位和求职训练 Artifact，保留原 Source、图谱、代码提交和面试；整场面试可在 V2.4 单独预览删除。事件不复制岗位描述、代码或回答，删除后仅保留无岗位/训练标识的计数。

功能开关、API 和回退详见 [API_SPEC](../docs/API_SPEC.md#413-v25-求职训练中心)；工程验收与限制见 [阶段交付](../../docs/V2_5_CAREER_DELIVERY.md)。
