## 队列是什么

队列遵循先进先出：先进入的元素先离开。入队在队尾添加元素，出队从队头移除元素。
生活中的排队取号就是一个类比：先取号的人优先获得服务。

## 循环队列

数组实现中，可以让下标到达数组末端后回到开头。若使用一个空位置区分队空与队满，容量为 N 的数组最多保存 N−1 个元素。
队空条件为 front == rear；队满条件为 (rear + 1) % N == front。
入队后更新 rear = (rear + 1) % N；出队后更新 front = (front + 1) % N。
