## 三、Prompt 文件说明

### 3.1 classify.md — 分类 Prompt v2

**功能：** 让 AI 判断文件属于哪个类别
**输出格式：** JSON `{"category", "confidence", "course_name", "reason"}`
**分类规则：** 5 条判断规则 + 易混淆类别区分章节
**当前版本：** v2（含参考资料 vs 作业、课件 vs 作业、待确认 vs 其他区分说明）

### 3.2 extract.md — 实体抽取 Prompt v2

**功能：** 从文本中提取 5 个关键字段，自动判断文件类型
**输出字段：**
- `file_type` — 文件类型（course/competition/exam/admin/other）
- `course_name` — 课程名称
- `task_description` — 任务描述（≤15 字）
- `deadline` — 截止日期（YYYY-MM-DD）
- `location` — 地点
- `extra_entities` — 其他有用信息（字典）
**当前版本：** v2（五类型适配，竞赛/行政通知也能抽取）

### 3.3 milestone.md — 多里程碑识别 Prompt v1

**功能：** 从竞赛/大创通知中提取所有关键时间节点
**输出格式：** JSON 数组 `[{"event", "date", "order"}]`
**触发条件：** 仅竞赛通知和大创通知时调用
**当前版本：** v1（含 4 个 few-shot 示例 + 日期处理规则 + 去重规则）

### 3.4 naming.md — 命名规范说明 v1

**功能：** 命名生成器的规则说明
**命名模板：** `[课程]-[类型]-[任务]-[截止]-[状态]`
**文件名最大长度：** 80 字符
**当前版本：** v1（task 限制 15 字，LLM 精简 + 硬截断 fallback）

## 八、接口契约

### 8.1 我对外提供的接口

| 接口 | 输入 | 输出 | 调用方 |
|---|---|---|---|
| `Classifier.classify(text, filename)` | 文本 + 文件名 | `{category, confidence, course_name, reason, method}` | PipelineWorker |
| `EntityExtractor.extract(text)` | 文本 | `{course_name, task_description, deadline, location, extra_entities}` | PipelineWorker |
| `MilestoneDetector.detect(text)` | 文本 | `[{"event", "date", "order"}, ...]` | PipelineWorker |
| `Namer.generate(category, course, task, deadline, status, extra_entities=None)` | 6 个字段（末位可选） | 文件名 str | PipelineWorker |

> ⚠️ **接口变更待胡希同步 `API_SPEC.md`（2026-07-31）**
>
> `Namer.generate()` 新增**可选**关键字参数 `extra_entities: dict | None = None`。
>
> - **向后兼容**：默认 `None`，现有 4 处调用（`agent_coordinator.py:380`、
>   `pipeline_factory.py:297`、`backend_api.py:433`、`main.py:143`）无需修改即可正常工作。
>   已有测试 `test_extra_entities_optional` 保证这一点。
> - **作用**：`course` 为空时从 `extra_entities` 取主办方（organizer / 主办方 /
>   发文单位等 8 种键名）补位第一段。竞赛、大创、行政通知本身没有课程名，
>   此前只能填「未分类」。
> - **⚠️ 调用方需传参才能获得提升**：不传 `extra_entities` 时行为与旧版完全一致。
>   建议上述 4 处改为传入 `extra_entities=entities.get("extra_entities")`。
> - **实测收益**：W4 联调 20 份样本，命名通过率 **15% → 75%**，
>   不区分类别的零占位率 15% → 45%。详见 `docs/联调测试报告_W4.md`。
