# 布局、交互与视觉基线交付

2026-10-03。依用户最新要求进一步完善全局布局、六站参考动效与图标，随后固定开发流程并启动后续任务。本轮交付为本地工程基线；线上仍是旧快照。

## 用户可见变化

- 保留LOGO和钴蓝光束大背景。公共导航、完整工具查找、首页与知识库切换为Tabler线性SVG；许可证随静态资源分发。
- 相关功能采用移动选中底板，窗口变窄/换行后重新对齐；页面进入、图标悬停和学习链展开提供短反馈，减少动画时静态。
- 知识库采用单一大检索入口、三个学习/证据入口和宽资料列表。去掉检索范围下拉，从资料卡选择范围，以可清除标签显示；资料名就地筛选。
- 资料标题20–21px、检索输入18–20px、正文18px，主要操作至少44px。六阶段学习链与产物按需展开，阶段计数来自实际存储。
- 笔记以标题和段落阅读，卡片/练习深链到原学习工作区。编辑弹窗有键盘焦点保护和未保存离开确认，保存中阻止关闭，格式错误不写入。
- 迟到响应不能串入另一份资料，失败可就地重试。匿名检索反馈对应已执行的问题；删除后清理失效范围、结果与产物列表。

六站实际核对、使用和访问限制见[开发流程v2](DEVELOPMENT_WORKFLOW_V2.md#六站参考与落地方式)。Aceternity与React Bits仅参考交互模式，用Vue和既有Anime.js原创实现；新增依赖只有`@tabler/icons-vue@3.48.0`。LOGO未修改。
