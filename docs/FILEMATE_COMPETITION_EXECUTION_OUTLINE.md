# FileMate 竞赛型 AI 学习产品执行大纲

版本：1.0
周期：30 天达到可参赛版本，60 天达到完整展示版本

## 一、产品定位

FileMate 不再只是“AI 文件整理器”，而是一套本地优先的大学生学习智能体：把散落的课件、作业、考试通知和个人作答沉淀为可追溯的学习资产，再形成“资料理解 → 练习评测 → 错因诊断 → 动态计划 → 能力验证”的闭环。

一句话创新点：**让每个 AI 建议都能回到学生自己的资料、题目和学习证据，并能被确认、撤销和复核。**

### 目标用户

- 大学生：管理课程资料、备考、竞赛学习、求职面试。
- 教师/指导老师：查看匿名化学习效果与资源质量，不读取学生私密原文。
- 竞赛评委：在 7 分钟内看到真实输入、AI 推理证据、可量化改进和完整交付。

## 二、竞赛方向映射

| 方向 | FileMate 对应能力 | 参赛证据 |
| --- | --- | --- |
| 中国软件杯大模型个性化学习/多智能体 | 多维学习画像、资源生成、动态路径、效果评价 | 真实课程数据、Agent 轨迹、前后测结果 |
| 中国软件杯 AI 数字人 | 数字人导师、模拟面试、校园学习讲解 | 端到端延迟、评分量规、演示录像 |
| 中国大学生计算机设计大赛 AI 应用/AI 辅助教学 | PDF 理解、知识卡、题目与错题、学习计划 | 源码、说明书、用户手册、演示视频 |
| 挑战杯“人工智能+” | 本地隐私、可信执行、大学生成长场景 | 项目计划书、社会价值、调研与测试材料 |

赛题每年会调整，报名时以官方题目 PDF 和允许使用的模型/工具清单为准；产品层保持模型与数字人供应商可替换。

## 三、可行技术栈

### 客户端与前端

- 桌面壳：Tauri 2，输出 Windows NSIS 与 MSI。
- Web UI：Vue 3 + TypeScript + Vite + Pinia + Vue Router。
- 组件与图标：Element Plus + `@element-plus/icons-vue`，避免多套图标风格。
- 图表：ECharts，仅用于真实学习数据与评测，不绘制虚假趋势。
- 通信：Axios 调用本机 FastAPI；数字人/流式输出阶段增加 WebSocket。

选择理由：现有代码已采用该栈，继续演进的风险和 30 天交付成本最低；Tauri 安装包体积与本机文件能力也适合学习桌面工具。

### 后端与 AI

- API：Python 3.12 + FastAPI + Pydantic + Uvicorn。
- 打包：PyInstaller Sidecar，用户机器不要求安装 Python。
- 数据：SQLite + FTS5；文件与生成产物落本机应用数据目录。
- 检索：第一阶段采用 FTS5 + 向量适配器的混合检索，不立即引入独立向量数据库。
- Embedding：抽象 `EmbeddingProvider`，可接 BGE-M3 本地服务或 OpenAI-compatible embedding API。
- 大模型：复用现有 `LLMClient`，以 OpenAI-compatible/LiteLLM 接口适配 StepFun 等模型；密钥只读环境变量。
- 多智能体：先用显式 Python 状态图实现 Planner、Retriever、Resource、Evaluator 四类 Agent；状态可落库、可重放。30 天内不引入重量级 Agent 框架。
- 文档解析：现有 PDF/Office 解析链路；OCR 作为可选能力，不纳入最小桌面运行依赖。

### 数字人与模拟面试

- 会话编排：FastAPI WebSocket + 明确的面试状态机。
- 语音：流式 ASR/TTS 供应商适配层，文本模式必须可独立运行。
- 形象：首版使用 2D 口型/状态动画；60 天版再接云端数字人或 WebRTC 流，保留供应商替换接口。
- 评分：岗位能力量规、STAR 结构、事实一致性、表达清晰度；每一项给出原句证据，拒绝只给总分。

这个降级路径保证：即使没有摄像头、麦克风或付费数字人服务，模拟面试仍能完整运行和评测。

### 工程与发布

- 测试：pytest、前端类型检查、Vite 构建、Sidecar 冒烟、无 Python 安装/卸载测试。
- CI：GitHub Actions Windows Runner；上传安装包、测试报告与验收 JSON。
- 安全：文件白名单、路径边界、确认后执行、幂等、撤销、日志脱敏；API Key 不入库。
- 可观测：请求 ID、模型/提示版本、检索引用、耗时与失败原因；默认不上传学生原文。

## 四、功能架构

```text
学习资产层
  文件导入 / 分类 / 命名 / 日程 / 来源定位
        ↓
知识理解层
  PDF 摘要 / 章节笔记 / 可追溯问答 / 知识卡
        ↓
练习评测层
  题目生成与提取 / 作答 / 题目分析 / 错题本 / 间隔复习
        ↓
个性化层
  六维画像 / 薄弱点 / 动态计划 / 多智能体资源生成
        ↓
能力验证层
  模拟考试 / AI 模拟面试 / 数字人导师 / 成长报告
```

### 六维学习画像

1. 知识掌握度：知识点正确率与复习后变化。
2. 错因结构：概念、审题、计算、记忆、表达、时间分配。
3. 学习节律：可学习时段、持续时长、计划完成率。
4. 资源偏好：例题、图解、讲义、闪卡、口述问答。
5. 任务压力：考试/DDL 距离、任务量与风险。
6. 迁移能力：新题、综合题和面试问题中的应用表现。

画像的每个结论必须关联观测样本数和更新时间；数据不足时显示“待评测”，不能伪造百分比。

## 五、30 天执行路线

### 第 1 周：可信底座与产品统一

- 完成 Windows 安装包、Sidecar、自启动/退出、安装卸载验收。
- 固化设计系统，重做应用壳与学习工作台。
- 统一学习资产、知识点、题目、作答、错题的数据模型。
- 验收：干净 Windows 无 Python 可安装；核心页面无乱码；所有操作有空/错/等待状态。

### 第 2 周：知识库与可追溯问答

- 文档切片、FTS5、embedding 适配器、混合检索。
- PDF 摘要、笔记、问答统一为“学习产物”，保存提示版本和引用片段。
- 原文定位、引用命中测试、无答案拒答。
- 验收：指定测试集的引用命中率 ≥ 85%；答案不能引用不存在的片段。

### 第 3 周：题目、错题与学习计划

- 题目提取/生成、作答、答案解析与知识点映射。
- 错题本、错因标注、相似题、间隔复习队列。
- 六维画像 v1；Planner 根据考试日期、薄弱点和时间生成计划。
- 验收：一份课件可走完“理解—练习—错题—复习—计划更新”。

### 第 4 周：多智能体与竞赛交付

- Planner/Retriever/Resource/Evaluator Agent 状态图。
- 生成至少五类资源：讲义、闪卡、例题、测验、口述问答。
- 完成匿名评测集、演示账号、7 分钟演示脚本、架构图、用户手册。
- 验收：全新环境按 README 可复现；Agent 步骤与引用可审计；关键用例录屏成功。

## 六、60 天完善路线

### 第 5–6 周：AI 模拟面试

- 岗位/竞赛答辩题库、追问策略、文字与语音双模式。
- STAR 证据抽取、分项评分、改进示范、复盘报告。
- 增加网络中断、ASR 失败和服务降级测试。

### 第 7 周：数字人导师

- 2D 数字人舞台与口型状态；可选接入云端数字人供应商。
- 教材讲解、面试官、答辩评委三种角色模板。
- 测量首字延迟、首音延迟、对话中断恢复与成本。

### 第 8 周：效果验证与竞赛包装

- 10–30 名学生小规模可用性测试，记录前测/后测与任务完成时间。
- 消融实验：无画像、无检索、无 Evaluator 与完整方案对比。
- 完善项目计划书、技术白皮书、答辩 PPT、演示视频和知识产权清单。

## 七、评测指标

| 模块 | 核心指标 | 最低验收 |
| --- | --- | --- |
| 文档解析 | 页/段解析成功率 | 测试集 ≥ 95% |
| RAG | 引用命中率、无依据回答率 | ≥ 85%，≤ 5% |
| 题目抽取 | 题干/选项/答案结构准确率 | ≥ 90% |
| 错题诊断 | 教师/人工一致率 | ≥ 80% |
| 学习计划 | 任务可执行率、完成率变化 | 可执行率 ≥ 90% |
| 面试评分 | 两位人工评分相关性 | Spearman ≥ 0.70 |
| 数字人 | 首音延迟、中断恢复率 | ≤ 2.5 s，≥ 95% |
| 桌面交付 | 安装、启动、退出、卸载 | 100% 自动冒烟通过 |

所有阈值都必须由版本化测试集和原始报告支撑；未达到时公开标注，不用宣传话术代替证据。

## 八、演示主线

1. 导入真实课程 PDF 和考试通知，展示可信分类、日程与可撤销归档。
2. 生成带原文引用的摘要和知识卡，追问一个资料中不存在的问题并正确拒答。
3. 完成五道测验，其中一道答错；系统说明错因并加入复习队列。
4. 学习画像从“待评测”更新为有证据的薄弱点，计划自动调整。
5. 进入模拟面试/答辩，数字人追问并给出带原句证据的分项反馈。

这条主线同时证明产品价值、AI 创新、可信性、工程完成度和可展示性，避免把比赛演示变成互不关联的功能巡游。
