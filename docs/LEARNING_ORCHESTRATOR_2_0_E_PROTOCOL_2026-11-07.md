# E 级真人实验协议与工程准备（2026-11-07 启动）

**状态：工程准备就绪，真人实验尚未开展。** 本文件只定义协议、字段与工具边界，不含任何参与者数据、不生成任何学习效果数值。按项目规则，`learning_improvement` 在所有工程数据中保持 `null`；只有真实采集、经同意、可审计的受试者数据才能写入研究结果，且不得由智能体代填或推测。

## 为什么不能「现在运行完成」

E 级真人实验的受试者是真实的人。它需要：招募与知情同意、分组与随机顺序、先验水平测量、真实任务与证据、模型版本与用量记录、实际编辑行为、实际完成情况、以及次日/随访测量。这些环节依赖真实参与者和时间跨度，智能体无法代替参与者产生数据；伪造数据会违反项目不变量「无数据时显示待评测，不生成虚假准确率、趋势、画像或用户研究结果」。本轮完成的是让实验**可以合规启动**的工程准备。

## 实验设计框架（待伦理确认与招募后执行）

- **目的**：比较三种条件在同一证据与同一预算下的实际差异，不预设结论。
- **三条件**：`rule`（纯本地规则）、`model_explanation`（单次授权的模型解释）、`manual_edit`（用户自行编辑）。三条件共用同一证据集合与同一时间预算。
- **设计**：受试者内／受试者间二选一须在招募前固定；若受试者内，条件顺序须随机化并记录顺序，防止学习效应与疲劳偏差。
- **样本**：样本量、纳入/排除标准、先验水平分层方式须在招募前预先登记；不得事后按结果调整。
- **盲法**：评分者与条件标签分离，评分规则预先固定。
- **伦理**：书面知情同意、可随时退出、数据最小化、匿名化存储、留存期限与删除方式须在招募材料中明确；涉及在校学生时建议先经所在院系/指导教师审阅。

## 必须采集的字段（工程数据契约）

| 类别 | 字段 |
|---|---|
| 参与者 | 匿名 participant_id、招募来源、同意版本与时间戳、退出记录 |
| 先验 | 先验水平测量结果、分组、随机顺序种子与分配记录 |
| 条件 | condition ∈ {rule, model_explanation, manual_edit}、证据 ID 集合、预算、时间盒 |
| 模型 | provider、model 版本、prompt 版本、token/费用用量、失败码、回退事件 |
| 行为 | 实际编辑次数 actual_edit_count、实际采纳/拒绝、请求键与幂等回执 |
| 结果 | 实际完成、时间戳、随访结果与时间点 |
| 质量 | 违规计数（重复/超预算/无关/过期/跨课/历史损害）、偏离协议记录 |
| 隐私 | 正文外发逐次授权记录、删除与备份恢复事件 |

**红线**：`learning_improvement` 仅在真实数据齐备且经统计方案计算后填写；任何合成、演示或夹具数据一律保持 `null`。

## 工程复用接口（已存在，无需新建功能）

- 三条件静态评测：`evaluation/evaluate_learning_coach.py`，结果字段固定为 `evidence_unsupported`、`duplicate_actions`、`overbudget_days`、`irrelevant_actions`、`stale_evidence`、`crosscourse_evidence`、`history_damage`、`actual_edit_count`、`learning_improvement`。
- 四目标原模块写入与重放：`scripts/acceptance/learning_coach_journey.py`。
- 容量与运行时：`learning_coach_performance.py`、`learning_coach_runtime.py`。
- 试行版记录与隐私：`filemate/study/trial/`、现役 `data_actions` 与备份恢复。

## 启动前检查清单

1. 取得伦理/指导教师确认与知情同意文本定稿。
2. 固定样本量、随机方案与分析计划（预先登记，不可事后改）。
3. 确认模型供应商密钥与费用授权，记录真实 usage；无授权则明确记为待验，不用合成结果替代。
4. 完成招募并采集同意时间戳；建立匿名 participant_id 映射并隔离保存。
5. 每人分别运行三条件，记录真实编辑与实际完成，禁止由智能体代填学习提升字段。
6. 次日/随访按预定时间点采集，记录失访与偏离。
7. 数据与同意记录按留存期限保存，到期删除；报告区分工程结果与真人效果。

## 与 D 阶段的边界

D 阶段是工程验收（本次已由用户确认）。E 阶段是真人效果研究，两者结论不得互相替代；工程门禁通过不代表学习效果得到验证。生产 D 开关与试行开关的启用属于部署动作，与真人实验的伦理准备相互独立。
