## 架构与数据模型

Vue3／TypeScript工作台通过统一 services/api 调用 FastAPI；所有课程读写使用现有身份解析后的 SQLite 存储。Source 原文、Artifact题集、quiz_attempts、wrong_questions与StudyPlan继续复用，未创建第二套题库或用户画像。ECharts使用有界画布，列表／搜索分页访问完整课程。

B身份以课程、来源版本和原概念为基础；C只读快照统一关系、筛选、搜索、证据和代表概念。D追加人工题目摘要映射、跨课导航、计划日关联、持久工作及来源依赖。合并只改变代表投影，原概念和作答身份不被重写；撤销融合后证据按原映射分开。

业务迁移32／33／34追加外键、唯一键、索引和删除触发器。33补全正式题集及修订历史的多源依赖，避免只删工作草稿却遗留资料正文。控制账本3独立记录非退款的课程准入；个人备份不能复位24小时额度，管理员整站备份独立处理其恢复。schema31个人备份升级后仍可读，回滚必须使用完整备份及匹配代码。

34补齐旧问答的完整课程来源依赖，恢复个人备份时同样补齐；新问答保守绑定全部课程来源，含无效或未进入12条引文采样的来源。代价是删除课程资料可能额外清除部分历史问答。独立审阅六项Important已各有先失败后通过的回归，原审阅报告与修复边界另附，不声称有第二次独立复审通过。

## 训练状态与解释

状态 `course-training-v1`：近7天真实错答或到期且未掌握的复习→需要巩固；近30天至少3道不同正确题、跨2个上海日期，同时无近7天错答／无到期复习→近期表现稳定；其他有有效作答→已有练习；没有→暂无证据。所有时间窗含下界且不纳入未来／异常时间。状态只是近期训练表现，不能推断整体掌握、情绪或能力。

题目归属必须人工确认现役题集ID、题号和规范摘要；修订历史不当成当前题表现。作答按 attempt_id 去重，未知网络重试可提供稳定 request_key。批量投影避免逐节点 N+1，详情只返回每类50条分页与精确总计数；计划完成单列。证据摘要绑定输入记录及当前窗口摘要，跨窗口后的历史问答标为过期。

证据查询按去重后的映射／修订身份驱动Artifact索引，每个题集只读一次作答范围，不扫描全部无关作答；1000映射＋10000无关及10000相关作答通过SQLite VM步数回归。路径主要构建放在读快照，短写事务检查同连接数据库版本及写计数。无关写入也可能产生保守409，已确认请求先读回执以维持幂等。此机制测试不能代替目标服务器的并发容量评估。

## 练习、推荐与有限 Agent

规则练习把有效连续原文中的概念遮空；无法证明难度或语义质量。模型练习输出结构化 JSON，核对现役题型、答案、引用 ID与原文；格式通过仍不等于题意正确，正式写入前每题人工审核。

学习路径只使用有效同课已确认 prerequisite／depends_on；先检测环，再有界拓扑排序。到期复习、近期错答、选中范围与章节构成透明优先级，前置顺序优先。章节是硬交集，外部前置计数与名称提示；任务最多7项、每日一项，不超日预算。独立确认新增现役计划，可归档撤销／恢复，用户改写后返回冲突。

Agent固定读范围、读训练事实、读引文、规则计划预览四步，不执行模型任意工具名。最多30个上下文概念、12段／12000字符引文、60条已确认关系，明确披露覆盖范围。回答分原文依据、服务端个人事实和建议；只接受白名单引用和事实ID。模型建议的语义仍需用户判断，引用存在不能证明建议正确。

## 可靠性、安全与隐私

模型通过现有可替换 Provider／LLMClient 适配层，服务端配置或注入适配器可替换；浏览器密钥只发送到现有可信 DeepSeek 端点，不能随共享 base_url 改投任意站点。新请求逐次授权，密钥仅请求上下文，接口日志和数据库不保存。单次20秒、一次调用、无自动重试；模型在写事务外运行。

工作先持久化并领取租约，每课程一个运行、24小时最多30次。取消、来源变化、备份恢复及租约超时阻止晚到结果复活；历史读取不调用模型。来源／题目／目标／窗口摘要在确认或完成前再核对。写入预览、确认和幂等回执，失败保存固定错误码；数据库故障脱敏503，现有学习内容继续保留。

移出课程和彻底删除有不同后果；后者的影响预览包含多源派生产物及其下游，不静默覆盖。账户空间、跨课两端、严格查询／JSON参数、反向联系去重、默认开关和备份恢复由实际回归测试验证。无任意 SQL、代码、文件删除或画像写权限。

## 评测方法与实测边界

质量工具按规范ID集合算概念 P/R/F1，按有向带类型关系三元组算关系 P/R/F1。人工引用支持、融合正确和错误关系拒绝率同时列有效标注数、未标注数与覆盖率；分母0为 null。要求授权记录及至少两名标注人，不把 AI 输出当 gold。

合成 JSON只验证计算器。性能脚本在新隔离绝对目录构造100／1000／10000节点，每组10000作答，以真实 localhost HTTP记录首1／热5与四读＋重复确认。14条投影SQL的初步结果不随节点规模线性增加，实际最终耗时、进程树RSS、DB／WAL保留在交付证据；不据此声称多人服务SLA、浏览器heap或真实提取质量。C首次3007.3ms略超3秒未被新实测解决。

研究协议提出普通阅读练习、图谱、图谱＋证据三组，等时训练、基线与延迟7天测验、盲评、预设 C-A／C-B 比较及缺失敏感性分析。初步90人不是功效保证；须单独批准协议、资料授权、招募与数据管理后采集。当前无真实学习提升比例、无正式准确率、无虚假成长统计。

## 可扩展性与限制

业务模块、只读投影、工作租约、Provider和质量CLI有明确边界，可后续加入经授权的专业课程、人工 gold及受控研究。当前全课程投影仍需线性扫描本课证据，密集并发会增加耗时；未声称无限规模。跨课程只做人工导航；没有跨课能力累计、向量检索、图数据库、任意自治工具或正式组织评审。部署、真实设备、浏览器 D／E 实测和真实供应商质量属于未完成验收条件，工程候选不等于正式发布。
