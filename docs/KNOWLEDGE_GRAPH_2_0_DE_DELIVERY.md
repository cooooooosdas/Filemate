## 用户可见结果

- 在课程知识点内查看真实作答、错题、到期复习与计划记录。状态依据 `course-training-v1`，说明样本、时间窗与规则，不生成掌握率；任务完成不等于答对。
- 人工关联现有题目，或从原文生成待审核的填空／模型草稿；逐题接受、拒绝或修订，确认后进入原有题集、判题和错题本。网络未知时同键重试只记录一次作答。
- 依据有效同课前置、到期复习和真实错答预览最多七天的计划，独立确认后新增；可撤销、恢复，保留进度，不覆盖手工计划。章节外前置明确提示，用户可扩大范围重做预览。
- 人工跨课联系仅作导航；目标失效会提示并允许解除，不混合课程训练记录，不充当前置关系。
- 助手把原文引用、服务端训练事实和学习建议分开。规则检索可离线使用；模型解释须逐次授权，失败留失败状态。历史只读，不自动重发模型。
- Agent 固定四个读取／预览步骤，最多七项任务。无删除、代码执行、任意工具、画像修改权限；写计划需要独立确认。

## 全链、故障与数据边界

`test_growth_lifecycle.py` 使用公开 HTTP：注册→退出／登录→两份数据结构原创合成资料→逐项审核→课内融合→第二课程隔离→练习审核→真实错答／再答→错题与状态→计划确认／重复／撤销／恢复→今日完成→规则问答→四步 Agent 预览→导出→删除第二来源→恢复备份→旧预览拒绝→旧结果读取。没有用真实学生资料，不能据此声称真实学习有效。

既有专项回归覆盖模型超时、格式错误、未知引用、取消／恢复期间晚到、来源修订、数据库异常脱敏、跨租户、开关回退、非首来源彻底删除与历史题集依赖。正式题集、计划和回答绑定全部参与来源；移出课程保留历史但停止当前依据推荐，彻底删除依赖来源按预览清除派生产物。个人恢复清预览、轮换 epoch、中断运行，不重放模型。schema31签名个人备份升级34后的恢复另有实测。

## 规模与性能

详见 [全部脱敏样本](audits/knowledge-graph-2-de-2026-10-23/)。每组首调用一次、热调用五次；不清 OS 缓存，不声称总体 P95。详情分页50项，画布仍最多100概念／300关系；不是在浏览器同时绘制10000个节点。实际进程树 RSS 与浏览器 heap 分开，浏览器资源没有测量则为 null。

C阶段保留的首次画布 **3007.3ms** 慢样本仍略超3秒；随后2848.7ms不能替代它。D／E本轮恢复浏览器主流程实测，但没有重测10k画布，不能声称已定位或修复这个瓶颈。新接口热调用目标为2秒；并发四读＋同一确认两次另列原始耗时，不能用单请求成绩代表多人性能。

## 开关、迁移与回退

后端 `FILEMATE_ENABLE_COURSE_GRAPH=1`，前端 `VITE_ENABLE_COURSE_GRAPH=true` 开启课程工作台与 D；E 另需后端 `FILEMATE_ENABLE_GRAPH_ASSISTANT=1`、前端 `VITE_ENABLE_GRAPH_ASSISTANT=true`，均默认关闭。关闭保留旧图谱；助手关闭时已有工作仍可从课程工作接口读取。前端构建开关需重新构建。

业务追加32／33／34，治理账本追加3；旧迁移不改。个人恢复不包含控制账本；新增准入仅存归属及课程／请求的哈希、输入摘要、时间，不存问题、引文或密钥。每日额度同时保留业务回执与独立控制准入；故障在两次提交之间发生会消耗一次额度，采用失败关闭。准入墓碑保留30天、账户删除清除其归属记录，管理员整站备份单独包含控制账本。

34补齐旧问答的课程来源依赖，个人备份恢复同样补齐；新问答也绑定全部课程来源，含未采样和已移出来源。删除任一课程来源可能保守清除部分与该来源无直接引文关系的历史问答，避免残留标签／训练摘要；需要时重新生成。模型个人统计和能力结论采用保守拒绝，仍不把语词校验当通用语义证明。

**不提供 down migration。** 发布前备份业务、控制账本和托管文件，在隔离目录演练恢复；回退使用兼容 schema34／治理3的代码，或在停写后恢复升级前的完整备份与配套旧代码。后者会丢失备份之后的变更，需负责人决定，不能靠关前端按钮冒充数据库回退。生产停写备份与独立恢复已执行并通过；公开写入后只使用保留当前数据的兼容代码／关闭版回退，长期低配置容量仍待验证。
