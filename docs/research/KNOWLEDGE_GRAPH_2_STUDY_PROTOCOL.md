# FileMate 知识图谱 2.0 学习研究协议草案

版本：KG-STUDY-1，2026-10-23。状态：**pending_approval，未招募、未采集、无学习效果结果**。本文件是研究准备，不能当作伦理批准、知情同意记录或比赛中已经取得的成效。

## 研究问题与分组

在相同授权课程内容、学习时长和测验条件下，图谱与证据推荐是否改善延迟知识测验表现？首课数据结构，第二课用于隔离与外推可行性检验，不混合不同课程的训练证据。

| 组 | 条件 | 控制要求 |
|---|---|---|
| A | 阅读资料与普通练习 | 与其他组相同资料、题库及学习时间 |
| B | A＋人工审核的知识图谱 | 不开放D/E推荐；保留同样的人工帮助时间 |
| C | B＋真实证据推荐／有界学习助手 | 推荐和模型权限按实验前冻结版本；不得额外增加学习时间 |

初步可行性样本目标90名成年大学生，每组30人。它不是已达到统计功效的承诺；正式样本量需先定义最小有教育意义的差异，并用独立小样本方差、基线相关性、预期退出率重新估算。小样本试验不混入正式验证样本，不按显著性中途追加人数。若无法达到预设样本，报告可行性结果和区间，不包装为有效性证明。

按课程基础测验分层、在层内用独立程序随机分配并保存种子与分配日志；分配在完成同意和基线测验后揭示。避免任课教师掌握个人退出情况，参与或退出不影响成绩、评奖与平台权限。存在同班交流污染风险，记录发生情况；若改为班级集群随机，必须在招募前修订样本量和分析模型，不能直接沿用个人随机方案。

## 纳入、资料与流程

纳入自愿、年满18岁、具备基本浏览器操作且未参与题库制作的大学生。排除无法理解同意说明者；不按平台推测的能力或心理状态筛选。原始课程讲义应为原创或获授权，题库不能使用无权复制的书籍全文。

1. 研究者解释目的、时间、随机分组、外部模型使用、风险和退出方式，取得书面同意；模型外发独立勾选。拒绝模型外发者仍可普通使用平台，是否纳入研究按预注册规则决定，不在分析后调整。
2. 以匿名编号完成基础测验、课程接触史与设备可用性记录。收集完成研究所必需的信息，不收摄像头、人脸、情绪推断、简历或真实姓名到分析表。
3. 所有组接受等时操作培训；安排45分钟课程学习和15分钟练习。正式时长可在小试后一次冻结，三组一致；记实际时长、任务完成及技术故障，系统中断允许暂停实验计时并记录，不伪造学习完成。
4. 立即测验使用独立等难度题型，参考答案与评分规则先冻结。7天后（预设窗口±1天）进行延迟测验，内容与难度等价，题干不重复学习题。研究期间额外学习作为日志协变量，不按结果事后剔除。
5. 结束后收集同版可用性问卷及开放反馈。研究者解释三种条件，开放同等功能，提供退出与数据删除渠道。

## 结果与统计计划

**主要结果**：7天延迟测验得分，统一0–100。立即测验、任务完成率、实际学习时间、可用性问卷作为次要／探索结果，完整报告，不只选改善的指标。平台“近期表现稳定”是工程训练规则，不能代替研究结局。

测验由两名不知道分组的评分员按冻结量表评分；分歧按预设规则由第三人裁决，保留原评分和一致性报告。分析人员先用匿名组名锁定清理与统计代码，再揭盲。参与者无法对界面盲法，须在报告说明。

预设模型：延迟分数 ~ 组别＋基线分数＋随机分层变量。报告C−A、C−B的基线调整差、95%置信区间和两侧p值；两项主要比较构成同一检验家族，使用Holm逐步法控制家族错误率0.05：从小到大排序p值，先比较0.025，再比较0.05，遇首个未拒绝则停止拒绝后续；调整p值采用排序后累计最大值并截在1。不得以某组内前后显著、另一组不显著推断组间差异。

检查残差、范围上限、基线交互和组间异方差；预注册稳健标准误或合理模型的敏感性分析，不按显著性挑选模型。次要结果列明探索性，不据多次比较中偶然显著项下结论。课程不同或分层样本不足时，报告范围限制。

按随机分组报告所有同意且未要求删除的参与者流向。记录缺失时间、原因、退出、技术故障和各组缺失比例；不把缺失记0、不前值填充、不编造延迟测验。主要缺失处理方案应在正式采集前由统计负责人批准：基于预设基线与辅助变量的多重插补（假设MAR），并报告完整病例及MNAR偏移敏感性分析。若样本或数据不足以支持插补，明确主要效果未能可靠估计，报告可观察数据、缺失及宽区间，不能静默改作成功结论。

## 数据治理与退出

同意书与联系表分离保管；分析表仅包含随机匿名编号、组别、版本、测验、时长和必要故障记录。编号映射由独立负责人加密保存，分析者不持有。API密钥、Cookie、完整源文件路径和私人回答不进入公开结果。第三方模型接收的数据类别、实际供应商、端点、地域与保留政策需在同意前核验并填写，未核验不得以本协议替代授权。

参与者可随时停止，并在数据锁定前通过匿名删除码要求删除可识别原始记录；数据锁定日期、联系人和不可逆聚合边界须在正式同意书填明。暂定锁定为最后一次延迟测验后30天，原始去标识化研究表保存12个月；此期限仍需机构与用户批准。删除执行须记录并向参与者确认；备份中的副本按获批保留周期失效，并避免恢复后重新进入分析。退出后平台个人数据删除／导出与研究记录删除分别办理。

## 质量计算与工程证据的边界

`evaluation.course_graph_quality`只按给定人工gold计算概念集合P/R/F1、带方向和类型的关系P/R/F1、人工引用支持率、融合正确率及错误关系拒绝率。双人标注应先独立、再裁决形成gold；未判定项保留null，报告覆盖率。授权声明和标注者ID不是授权文件本身，需要审阅原始凭据。合成算例仅证明计算器算术正确，不是实际图谱提取质量成绩；工程100／1000／10000节点与合成全账户链也不代表教学效果。
