# FileMate 竞赛现场演示脚本（7 分钟）

## 演示前准备

```powershell
uv run python scripts/seed_demo_data.py --db _working/demo/filemate-demo.db
$env:FILEMATE_DB_PATH = (Resolve-Path _working/demo/filemate-demo.db)
$env:FILEMATE_INTERVIEW_LOCAL_ONLY = "1"
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1
```

演示数据库与个人真实数据隔离；如果目标文件已存在，脚本会拒绝覆盖。

## 时间轴

### 0:00–0:40：问题与定位

话术：大学生真正缺少的不是另一个聊天框，而是能把散落资料转化为学习行动、掌握证据和成长画像的个人智能体。

展示：首页自然绿色工作台，强调本地服务和“资料仅在本机处理”。

### 0:40–1:40：可信资料治理

操作：导入一份课程文件 → 展示分类、命名、截止日期建议 → 确认归档。

话术：AI 只能生成草稿，文件移动必须由用户确认；同名冲突不覆盖，失败自动回滚，执行后可以撤销。

### 1:40–3:00：可引用学习问答

操作：进入“资料理解” → 上传网络讲义 → 提问“TCP 如何建立连接” → 展示回答后的文件名、页码和原文片段。

话术：FileMate 不只给答案，还给出可核验引用；跨文档检索结果持久化到本地知识库。

### 3:00–3:50：练习与错题闭环

操作：生成练习 → 故意答错 → 打开“错题复盘” → 重新作答。

话术：错误会自动进入错题本，连续答对两次才标记掌握，避免“看过答案等于学会”。

### 3:50–5:20：数字人模拟面试

操作：选择“竞赛答辩” → 输入“中国软件杯项目答辩” → 启动 → 语音播报问题 → 回答 → 展示四维评分。

话术：同一套能力内核支持求职、保研和竞赛答辩；回答与评分可以选择本地隐私模式，也可连接配置的大模型。

### 5:20–6:15：成长数据与评测证据

操作：打开“成长数据” → 展示资料数、练习数、错题掌握、面试均分和能力维度。

话术：FileMate 的创新不是堆功能，而是把每次学习行为沉淀为可解释、可追踪的个人成长证据。

### 6:15–7:00：技术与结束语

展示：`docs/FILEMATE_EVALUATION_BASELINE.md`。

话术：系统采用 Vue 3、FastAPI、SQLite、Tauri 与可替换 LLM 层；当前有 262 项自动化测试，并提供可复现离线评测。我们会继续用真实匿名样本、双人标注和学生前后测验证教学效果。

结束语：FileMate 让文件不再只是被保存，而是进入理解、练习、反思和成长的完整闭环。

## 演示失败兜底

- 模型接口不可用：设置 `FILEMATE_INTERVIEW_LOCAL_ONLY=1`，面试使用本地评分；
- 网络不可用：检索、错题、面试数据和成长看板均可离线演示；
- 麦克风不可用：使用文本框回答，语音播报按钮仍可单独展示；
- 临时文件解析失败：切换到已准备的 TXT 或带文字层 PDF；
- 现场时间不足：只演示“引用问答 → 错题闭环 → 模拟面试 → 成长数据”四步。
