## 4. 操作与演示

1. 按README配置本地开发，启用 `FILEMATE_ENABLE_WRONGBOOK_V2=1`、`VITE_ENABLE_WRONGBOOK_V2=true`。图谱联动需同时启用现役课程图谱前后端开关；AI分析由既有AI开关和单次授权控制。
2. 先从已上传的原创课程资料创建练习并真实错答，再打开错题目录。无记录时正常显示空态。
3. 选择“推荐复习”并点击“查找”，查看原因；点击“开始本次复习”，填12分钟、每题4分钟，先核对题目与延后数量，再明确开始。
4. 独立回答后提交；刷新确认仍在原批次，再进入下一题。查看答案后的练习保持辅助标记；跳过不计成绩。
5. 返回目录查看原答、历史、来源与错因；只有明确预览并确认，才新增学习计划或采纳错因。今日学习、图谱练习回到原题而非泛化首页。

复现脚本 `scripts/acceptance/wrongbook_incremental.mjs` 只接受回环地址，需指向带 `.synthetic-wrongbook` 标记的新隔离夹具；凭据由环境变量提供。现役 `wrongbook_learning.mjs` 只连接本机合成模型，不能用它证明DeepSeek质量或真实学习效果。
