## 二、逐段画面与完整口播

### 00:00–00:15｜品牌开场（15 秒）

画面操作：

1. 先显示 FileMate Logo 约 2 秒。
2. 淡入首页，鼠标停在“学习工作台”主标题附近。
3. 不急着点击，让评审看清首页全貌。

口播：

> 大学生的资料往往散落在桌面、课程群和不同文件夹中，真正困难的不是拥有文件，而是把文件持续转化为能够复习、练习和证明成长的知识。FileMate，是一款面向大学生的本地优先智能学习工作台。

### 00:15–00:35｜用户自带模型密钥（20 秒）

画面操作：

1. 点击右上角齿轮，打开“应用设置”。
2. 展示 DeepSeek 模型服务卡片、模型名称和保存位置。
3. 输入框只短暂点击，不粘贴真实密钥；使用已配置状态演示。
4. 关闭设置。

口播：

> FileMate 支持用户使用自己的 DeepSeek API 密钥。密钥不会进入浏览器、业务数据库或项目代码，而是保存在当前 Windows 用户的系统安全凭据库中，保存后立即生效。这样既降低统一服务成本，也把模型使用权和数据选择权交还给用户。

### 00:35–00:55｜统一学习工作台（20 秒）

画面操作：

1. 缓慢扫过首页的处理记录、今日安排和最近资料。
2. 鼠标依次经过“导入资料”“读懂一份资料”“练一场面试”。
3. 点击“导入资料”。

口播：

> 首页不是功能堆叠，而是把今天最值得完成的事情放在前面。用户可以看到待确认资料、今日复习、最近学习记录，并从同一个工作台进入资料整理、知识学习、目标规划和模拟面试。系统会根据真实记录提示下一步，而不是展示虚构的进度，减少在多个工具之间反复切换。

### 00:55–01:30｜文件整理与安全确认（35 秒）

画面操作：

1. 拖入一份用于演示的竞赛通知或课程 PDF。
2. 展示系统识别出的分类、日期、关键词和建议文件名。
3. 进入“分类确认”或“命名确认”，手动修改一个字段。
4. 展示最终确认按钮与处理记录；不要真的移动重要原文件，可用演示副本。
5. 快速指向“可撤销”或历史记录。

口播：

> 导入一份资料后，FileMate 会解析内容，识别资料类型、课程或竞赛主题、关键日期与重要实体，再给出分类和规范命名建议。以这份竞赛通知为例，原本冗长、难以检索的文件名，被整理成包含类别、主题、截止日期和状态的结构化名称。系统不会静默移动、覆盖或改变文件类型。用户先预览建议，再逐项修改并明确确认；每次执行都会保存目标位置和操作记录，发生误操作时还可以撤销。FileMate 把内容理解和人在回路的安全确认结合起来，让整理既智能，也可控。

### 01:30–02:05｜个人知识库与学习资产链（35 秒）

画面操作：

1. 打开“个人知识库”，选择刚才或已有的一份资料。
2. 展示资料详情、来源状态和生成记录。
3. 指向“原始资料—摘要—知识卡—练习—错题—复习任务”的链路区域。
4. 打开一项已生成的学习产物。

口播：

> 整理并不是终点。资料进入个人知识库后，会保留文件名称、内容来源、授权状态和学习产物之间的关系。用户可以按关键词跨资料检索，也可以从原始材料继续生成摘要、结构化笔记、知识卡和练习题。答错的题目会进入错题本，再转化为复习任务；计划和面试也能引用同一份资料。这样，一份静态文件会沿着原始资料、理解、练习、纠错、复习和表达的路径持续产生价值。用户不仅知道生成了什么，还能追溯它来自哪里，形成连续、可检查的学习资产链。

### 02:05–02:45｜学习工作区与有依据问答（40 秒）

画面操作：

1. 进入“学习工作区”，选中一份已有资料。
2. 依次切换摘要、知识卡、练习或笔记，不必等待现场生成。
3. 在问答区输入一个与资料直接相关的问题。
4. 展示回答中的引用编号或来源片段。
5. 再切到一条历史会话，体现可恢复。

口播：

> 在学习工作区，左侧固定当前资料，右侧集中呈现可继续使用的学习成果。用户既能生成摘要、结构化笔记和知识卡，也能按需要生成练习题并直接作答。进入连续问答后，FileMate 会先从本地资料分块中检索相关内容，再组织回答，同时保留资料名称、页码或片段等引用关系。点击引用即可核对答案依据；当资料中没有足够证据时，系统会明确说明无法回答，而不是编造一个看似确定的结论。问答历史、引用和生成产物都会持久保存，重新打开后仍可恢复，让模型输出真正沉淀为个人知识，而不是停留在一次性聊天窗口中。

### 02:45–03:15｜目标反推、今日任务与错题复习（30 秒）

画面操作：

1. 打开“目标反推”，展示一个已有目标，例如“完成竞赛答辩”。
2. 快速扫过能力缺口、任务列表和重新规划入口。
3. 切到“今日学习”，勾选或展开一个任务。
4. 切到“错题复盘”，展示待复习状态。

口播：

> FileMate 不只生成一张静态计划。用户可以输入期末考试、竞赛答辩或求职准备等目标，再选择资料和截止时间。系统结合已完成的练习、错题和面试记录，区分已有证据与待评测能力，分析缺口并拆解为可执行任务。完成情况变化后，可以依据最新证据重新规划，同时保留已完成部分。练习中的错误会进入错题复盘，并按掌握状态和复习时间进入今日任务，让目标、行动、反馈和再规划真正形成闭环。

### 03:15–03:55｜真实模拟面试（40 秒）

画面操作：

1. 打开“模拟面试”，选择“竞赛答辩”、难度和一份授权资料。
2. 开启摄像头预览与麦克风检测；确保录屏前已允许浏览器权限。
3. 开始一道题，录入约 8 秒示范回答。
4. 展示回答时间轴、停顿或口头语标记。
5. 提交后展示内容结构、证据充分性、流畅性和改进建议。

口播：

> 模拟面试进一步还原真实表达场景。用户可以选择求职面试、竞赛答辩或保研复试，设定难度，并在明确授权后选择简历、项目书或课程资料作为提问依据。页面会分别申请摄像头和麦克风权限；录像只用于当前页面的本地预览与回放，不会自动上传。回答时，系统记录时长、语速、口头语和长停顿，并在时间轴标出不流畅的位置。提交后，评价不只给出总分，还会从内容准确性、逻辑结构、证据充分性、表达流畅性和时间控制等维度解释原因，并给出下一轮改进建议。用户可以回看具体位置、修正表达，再进行针对性复练。

### 03:55–04:18｜多 Agent 与可信边界（23 秒）

画面操作：

1. 打开“可信与隐私”。
2. 展示规划、资料、学习教练、面试、评价和安全六类 Agent。
3. 展示一次真实任务轨迹与共享记忆来源。
4. 指向资料授权、删除记忆或本地优先说明。

口播：

> 在后台，FileMate 不是让多个聊天窗口同时说话，而是由规划、资料、学习教练、面试、评价和安全 Agent 按任务协作。运行步骤、记忆来源和可用范围都可以查看和撤销。资料导入时还能声明本人所有、已获授权或公开来源，把隐私、版权和高风险操作确认直接做成产品能力。

### 04:18–04:30｜成长反馈与结尾（12 秒）

画面操作：

1. 打开“成长数据”，展示真实完成记录和学习伙伴反馈。
2. 最后回到首页或停留在品牌形象旁。
3. 画面淡出 Logo 与产品口号。

口播：

> 最终，FileMate 用真实学习记录形成成长反馈，让学习伙伴的状态回应每天的进步。FileMate，让散落的文件成为可行动、可追溯、可持续成长的个人知识。

## 三、AI 配音与剪辑参数

- 全稿按约 4 分 30 秒设计。AI 配音完成后，以实际音频为准：建议控制在 **4:22–4:35**，给片头、转场和结尾留出自然呼吸。
- 不要直接使用 1.5 倍或 2 倍播放速度；优先选择“自然、清晰、稍有活力”的音色，将语速设置为平台默认的 **0.92–1.00 倍**。AI 本身连读较快，盲目加速会让评审来不及看操作。
- 每段标题切换处插入 0.3–0.5 秒停顿；“本地优先”“先确认再执行”“引用关系”“可查看和撤销”等关键词可轻微重读。
- 若成片短于 4:20，不要拉长静音，应放慢关键页面的鼠标移动，并让引用、评分和 Agent 轨迹各停留 1–2 秒。
- 若成片超过 4:45，优先删除操作等待和重复转场，不要删去安全确认、引用依据与面试反馈三个差异点。

## 四、录制前快速检查

- 使用 1920×1080、30 FPS 录屏，浏览器缩放保持 100%。
- 提前准备一份无隐私的演示 PDF，并预生成摘要、知识卡、练习和一条问答记录，避免现场等待模型。
- DeepSeek 设置页只展示“已配置”，绝不在录像中粘贴或显示真实密钥。
- 摄像头、麦克风提前授权；关闭 QQ、微信、系统通知和可能弹出的个人信息。
- 所有测试数据明确为演示资料；成长数据只展示真实系统记录，不口播未经验证的准确率。
- 先录一条完整纯画面，再生成配音；根据配音时间轴裁切画面，最后补字幕和轻量转场。
