# V2.5 求职训练中心阶段交付

日期：2026-10-01～2026-10-02。范围：五大核心升级中的第五模块。V2.5为模块阶段号，应用版本仍为`1.3.0a1`。本阶段基于主线`8277bd5`整理为独立分支`codex/v2-5-career-training`并重新验收。GitHub交付状态以关联PR及CI为准；网站部署和EXE安装包更新不包含在本阶段，不重启用户原有服务。

## 用户影响

- 新增“求职训练中心”：搜索企业、岗位、地区和技能，区分校招、实习、社招参考与用户导入。内置两个企业、三个有官方链接及采集日期的短篇岗位摘要；不是实时职位聚合服务。
- 本地TXT/Markdown读取或粘贴岗位描述，按公开词表提取待核对要求，也可手动添加原句和训练类别。核对并确认后保存，草稿替换/删除有确认，失败保留输入；不自动抓网站或向模型发送岗位文本。
- 基础笔试使用七道平台原创固定题，按岗位要求选择最多五题；完整作答后按真实答案计算本轮结果。算法训练进入V2.3现有原创题和C++17隔离引擎，不自动执行代码。
- 岗位面试按确认的岗位快照创建五道原创项目/概念/定位问题/协作/复盘题，进入V2.4现役文字、语音、录像与复盘页；默认本地记录，内容分析继续使用逐题外发确认。不是企业真题或招聘方评分。
- 对比引用已确认图谱的真实作答、全部有效编程提交、该岗位基础笔试和实际面试记录。显示出处和计数，无样本显示待评测；不生成岗位适配率、能力总分或录用结论。可进入原知识节点、原提交及原面试继续训练。
- 保存当时的证据对比为Artifact，JSON/Markdown下载实际快照。岗位修改更新修订号，旧训练保留旧版本；撤销岗位停用新训练，恢复可继续，旧记录仍可读。
- 删除先预览影响并确认：只删除选定岗位与求职训练，保留原资料、图谱、代码提交、面试及Agent。面试仍可在V2.4独立预览删除。

## 数据和主要改动

SQLite v23追加升级到v24，历史迁移未改写。`career_positions`保存来源和岗位修订；`career_trainings`关联真实Artifact及现役面试；`career_events`只记有限操作和计数。创建岗位面试在一个事务内写入Agent步骤、面试、训练Artifact与事件，失败整体回滚。

保存键绑定岗位内容，训练键绑定岗位、类别和修订；已接收请求丢响应后同键返回原记录。编辑使用乐观修订，重复状态/相同作答/相同编辑幂等。删除令牌绑定全部训练内容，笔试提交或新增训练后旧令牌失效。损坏载荷标记异常且保留原字节，不自动改写原数据。

## 限制、回退及后续依赖

- 官方目录仅含三个训练摘要。采集日期不代表今天仍在招聘，岗位来源须再核对；腾讯参考岗位要求工作经验。没有企业合作或真实招聘题库。
- 标签关联是公开词法规则，需要人工核对。各图谱最近窗口可重复关联，同题跨轮基础作答可重复计数；面试完成量不代表能力达标。基础题汇总取该岗位最近100份训练，岗位列表显示最新200项；深链可读取更早记录。
- 代码引擎仍仅支持Windows C++17；Python/Java语言代码评测、其他平台沙箱、实时岗位刷新尚未实现。当前题库和合同为固定版本，未来改题应追加版本解析，不能重写历史标准。
- 真实供应商的岗位内容建议质量、真实导师校准、真实学生试用及长期学习/求职效果仍待评测。现役面试“待校准”边界保留，不以本次工程通过率冒充效果准确率。
- 后端`FILEMATE_ENABLE_CAREER=0`、前端构建`VITE_ENABLE_CAREER=false`可独立关闭新模块。保留数据及现役学习、图谱、编程、面试；重新开启恢复读取。不要降级数据库或改写旧迁移。

五个阶段的本地实现和各自验收已依次推进：[V2.1及可靠性补充](V2_1_1_DIGITAL_HUMAN_DELIVERY.md)、[V2.2](V2_2_KNOWLEDGE_GRAPH_DELIVERY.md)、[V2.3](V2_3_PROGRAMMING_DELIVERY.md)、[V2.4](V2_4_INTERVIEW_REVIEW_DELIVERY.md)、本阶段V2.5。后续为整体验收、网站与桌面发布；真实用户试用和导师校准仍需真实参与者，不能由工程测试替代。
