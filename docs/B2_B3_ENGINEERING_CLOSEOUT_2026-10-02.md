## B2 学习画像可解释、可回看

成长页新增证据说明面板，从持久化练习、错题、计划和面试聚合；每项提供样本数及单位、更新时间、计算依据、排除数量和最多5条最新原记录入口。没有数据显示待评测；少于5条显示样本不足；超过90天没有有效新记录显示历史数据。5条与90天是界面摘要规则，不是能力认证或研究门槛。

练习准确率按实际客观题作答次数计算，重复作答分别计数。错题掌握率依据现役连续答对两次的记录，不能解释为长期保持。计划完成率按有效未归档计划的数组日索引计算；同日期不同计划仍分别计数。面试仅聚合实际 `llm` 有效评分，每维度单独计算样本量；本地回退、异常 JSON、非有限值、越界和未来时间不形成能力结论。旧 SQLite 无时区时间按 UTC 兼容，损坏记录保留原字节。

API 为 `GET /learning-analytics` 新增 `evidence_profile`，不新增迁移。旧字段保留；旧计划汇总同步采用有效、未归档计划，避免损坏或已归档数据抬高完成量。[API 合同](../filemate/docs/API_SPEC.md)已同步。汇总只读，刷新不改计划；动态计划仍走已经验收的预览、用户确认、事务保存、幂等与撤销链。

研究与对照报告新增生成时间、输入记录数、有效日期覆盖和来源 SHA256。无测量日期的旧合成示例日期范围为 `null`，不把生成日期冒充测量日期。按条件分别报告区间；前后测先计算每名参与者的配对变化，再做固定种子42、2000次重采样的95%均值 percentile bootstrap。任务重复记录先按参与者平均，区间不把任务数当独立样本数。区间标明单位和参与者样本数；少于2名输出 `null`，零观察方差显式标记。该探索性算法依据 [SciPy bootstrap 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)中的重采样与百分位定义，不作显著性或因果结论，也不声称使用 BCa。
