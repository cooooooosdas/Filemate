# v1.3.0 版本说明草稿

2026-10-02，待团队冻结与正式试用验收；当前实际版本 `1.3.0-alpha.1`，不是已发布 `1.3.0`。

大学生学习工作台已串联本地资料导入、可回看的学习产物和问答、练习错题复习、学习计划、面试和求职训练。本轮补齐成长页的样本数、日期、公式和原记录说明；无样本、少样本、历史或损坏数据显示对应状态，本地回退不生成能力分。岗位计划延续先预览确认、再保存与撤销恢复。

开发与评测工具新增原创合成资料的实际模型闭环、严格匿名 CSV 校验、前后测/SUS与匿名任务导出、分条件探索性置信区间，以及代码指纹和 RC 证据汇总。不会自动生成真实参与者、问卷或导师评分。现役 schema 保持v24，成长统计 API 仅增加证据说明字段；旧计划统计排除归档与异常记录。

具体文件、测试结果和复跑路径见 [B2/B3工程交付](B2_B3_ENGINEERING_CLOSEOUT_2026-10-02.md)；此前五模块、原生判题、包装资源和服务器现状见[总验收](INTEGRATED_AUDIT_2026-10-02.md)。当前工作区未提交，远端 CI、线上版本和安装包不是这份草稿对应的冻结快照。

正式发布依赖真实学生 Beta、按协议开展正式研究、实际导师盲评、课程资料授权与结论使用审查，以及冻结提交、当前提交CI和网站同步后的验收。没有真实数据时仍为待评测。Linux网站原生判题、首访资源性能、数字人语音质量与音素同步按已记录的运行限制处理；不以工程成功替代学习效果证明。
