# 数字人讲话动画与实时面部动作

日期：2026-10-10。本卡依用户补充要求，在七项P1修复候选基础上改善两个既有模块，不扩展招聘、题库或Agent权限。后续导师语音切换为[Microsoft自然声线](MICROSOFT_NATURAL_VOICE_2026-10-10.md)，下方 Web Speech 验证为首轮历史证据。

数字人固定同一张人物立绘，SVG嘴部采用连续插值开合，辅以轻微呼吸/姿态动作；动画速度随语速调整，仅真实语音开始后运行，暂停、错误、停止、卸载归位，减少动态时关闭。口型是讲解节奏示意，Web Speech没有音频/音素输出，不能称为音素级口型同步、3D真实人物或音质改善。原画像与LOGO保留，没有再切两张人物截图。

视频面试复用已安装MediaPipe FaceLandmarker/同源WASM与模型，在Worker本地处理。视觉观察仍须用户先开启摄像头并主动开启；现在录像前也实时显示人脸状态、微笑/皱眉/张口系数及头部角度，每秒约2次。动作系数乘100用于易读展示，明确不是“紧张40%/开心20%”或心理、注意力概率。官方输出属于[面部关键点、blendshape系数与变换矩阵](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/web_js)，本轮没有经过验证的情绪概率模型，不伪造数值。无人脸/光线不足/停用时清空读数，错误保留原文字训练；原始实时系数不上传/持久化，也不参与内容评分；原观察摘要合同保持。

验证：42项前端单测、Vue类型、构建和体积通过；新增读数测试覆盖无脸、低光、非法系数及真实换算。实际本地CPU模型/合成公开图片视频验证录像前实时三项系数、实际录制、摘要保存、关闭后清空及同源加载，4项通过。面试完整回归首轮13/14，唯一失败为旧文案等待；更新等待实际实时面板后14/14通过，原失败保留。讲话连续插值6个不同帧、固定人物、暂停/恢复/停止、减少动态分支通过（合成语音设备事件＋真实API）。原生50字中文语音事件完成；500字暂停原脚本即时读取异步设备状态首轮失败，定向复测单独记录，未偷换为设备夹具通过。实际可听质量和真实学生学习效果未验收。
