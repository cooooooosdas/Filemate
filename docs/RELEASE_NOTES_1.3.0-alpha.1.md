# FileMate v1.3.0-alpha.1

发布日期：2026-09-12

这是一次以数据隔离和安全边界为核心的 Alpha 加固版本。

## 用户可见变化

- 网站生产环境中的不同浏览器访客不再共享资料、处理记录、学习计划、错题、面试或成长数据。
- 浏览器会获得一个签名 HttpOnly 匿名设备身份；数据按该身份使用独立 SQLite、上传目录和归档目录。
- 清除网站 Cookie 或更换浏览器相当于更换匿名身份，当前版本暂不支持跨设备账号找回。
- 分类、命名和日程页面在 Session 缺失或不可访问时会先清除旧状态，不再短暂显示上一份资料。

## 修复

- 封堵跨访客读取、修改、删除资料及 Session 执行记录的越权路径。
- 封堵通过可编辑 `entities.ics_path` 读取服务器任意文本文件的问题。
- 拒绝不受信浏览器 Origin 对网站 API 或本地 Sidecar 的状态变更请求。
- 资料详情和导入响应不再暴露服务器绝对路径与内部工作区字段。
- AI 上传解析或生成失败时回收未入库的托管副本，避免磁盘残留。
- 匿名租户数据库延迟创建；健康检查不会制造空数据库；打开的 SQLite 实例使用有界 LRU 缓存。
- 面试重复/并发提交改为明确冲突，不再因唯一索引异常返回 500。
- 学习计划多标签并发勾选在同一写锁内完成，避免完成进度丢失。
- 前端生产构建不再把 API URL 和后端错误写入控制台；学习伙伴最近事件不再跨匿名身份持久化到 localStorage。

## 验证

- Ruff 通过。
- 后端非 e2e 测试 462 项通过，18 项因可选 Office/PDF/OCR 夹具或系统权限跳过。
- 新增跨用户与安全边界测试 16 项。
- Vue 类型检查和 Vite 生产构建通过。
- 两个独立真实浏览器会话完成上传/历史列表隔离冒烟，控制台无错误。
- npm 生产依赖和 Python 依赖已执行已知漏洞扫描，未发现漏洞。

## 升级与数据边界

- 桌面端仍使用 `local` 单机模式，继续读取原本机数据库。
- 网站升级到匿名隔离模式后，新的访客数据写入 `DATA_DIR/users/<identity>/`。
- 升级前服务器原共享数据库不会自动分配给任一匿名访客，应先备份并作为受限历史数据保留；不要把其中内容批量复制给所有新身份。
- 生产身份签名密钥位于持久数据目录的 `identity.secret`，不得在有活跃匿名用户时随意更换。
