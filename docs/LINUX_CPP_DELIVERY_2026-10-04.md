# Linux C++判题与网站功能复核

现役网站运行在Linux，原Windows/MSVC隔离判题器无法执行。新增Linux客户端、独立受限Unix socket代理、固定GCC镜像及gVisor运行器。Windows原适配器保留；隔离不可用时关闭评测，不运行宿主代码。无需新增SQLite迁移，仍为schema v25。

编译器与测试点确定得分，AI代码复盘作为单独、需授权的参考结果保存，不能覆盖判题。Linux并发上限1，Windows上限2；页面根据`setup_supported`显示本地工具链准备按钮，根据实际Provider标识编译器。GCC错误行号进入同一份保守本地复盘。新增部署合同见[scripts/judge/README.md](../scripts/judge/README.md)，API与调用方同步。

服务器部署固定gVisor `release-20260928.0`（完整官方归档SHA512校验）与GCC14.2.0镜像，内容ID为`sha256:056a5a42fce98555fa7c8299cf0fd08e2ad4750cc40eb17afb84cc2404e9a9ba`。Docker新增专用runtime并重载配置，没有重启现有网站容器。Web用户仍不持有Docker权限；以`filemate`用户访问代理的真实隔离自检通过。程序只在gVisor容器内运行，单个学生进程、禁止网络、只读根文件系统和资源硬限制；停止服务及重启时清理专用标签遗留容器和专用临时挂载。

真实服务器GCC/gVisor合成回归12组通过：身份/宿主文件/根目录/网络/派生进程隔离，AC、WA、CE、TLE、内存限制、64KB输出洪泛、测试点文件隔离、16MB临时文件系统容量、学生伪造诊断不能替换运行器证据、运行中取消和完整清理。协议专项验证任意命令/路径/未知题目/自定义测试或资源被拒绝，取消与断连释放容量，缺失代理关闭执行；Windows本机专项52通过、1项Linux平台专用跳过。原生证据在`_working/linux-judge/`，只能说明工程隔离与判题行为。

本轮网站布局候选另有807项后端、35项前端、类型检查/生产构建/首屏预算通过；实际HTTPS网关47组、96个API路径、29项生产页面、17项归档审核、25项学习工作区、18项知识布局与12项视觉行为通过。网关里的模型为明确本地HTTP夹具；公网实际模型、账号和最新发布验证在上线后单独记录，不能以夹具替代。

范围仍限C++17及8道平台原创题，Python/Java代码仅可作资料阅读，暂无执行Provider。真实学生学习收益与面试专家校准尚未采集，邮箱归属验证及独立安装包仍是后续项。
