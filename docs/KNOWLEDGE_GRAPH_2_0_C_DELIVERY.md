## 性能实测

独立新建的合成SQLite库，各自只有指定规模；性能形状直接构造，不证明AI提取质量。脚本拒绝覆盖已存在或相对输出目录：

```powershell
uv run python -m scripts.acceptance.course_workspace_benchmark --output-root <新的绝对目录> --sizes 100 1000 10000
```

Windows 11，28逻辑CPU，Python3.12.13、SQLite3.53.1、FastAPI0.141.1。每规模每路径首调用1次、热调用5次；没有清空OS缓存，不称“物理冷缓存”，不据此声称总体P95。

| 总概念数 | workspace热最大HTTP | 搜索热最大HTTP | focus热最大HTTP | 首次有界画布可交互 | DB＋WAL |
|---:|---:|---:|---:|---:|---:|
| 100 | 6.226ms | 5.859ms | 6.410ms | 594.8ms | 2,276,416B |
| 1000 | 35.098ms | 17.799ms | 39.645ms | 576.4ms | 3,136,576B |
| 10000 | 143.415ms | 154.136ms | 146.866ms | 2343.0ms | 11,263,040B |

本机热门HTTP≤2秒、首次画布≤3秒的采样门槛均满足。浏览器是1366×768开发构建，模块已有缓存，计时从浏览器导航开始到画布flush及下一帧，包含本地读取；这是有界画布，不是10000节点同时绘制。各规模选择／缩放／重置采样期间Long Task记录为空，没有观测到>200ms任务；不代表所有机器和所有交互的上限。

浏览器接口不提供堆内存遥测，heap_bytes明确为null／未测。每规模HTTP日志实际统计workspace、搜索、focus各6次成功GET，POST为0；原始逐次耗时、序列化响应字节、返回节点数、服务时间、FK检查见[benchmark.json](audits/knowledge-graph-2-c-2026-10-22/benchmark.json)。浏览器数字另见[browser-scale.json](audits/knowledge-graph-2-c-2026-10-22/browser-scale.json)，不把未测字段填0。

## 功能与故障链

| 验证方式 | 实际结果 |
|---|---|
| 注册账户真实ASGI请求 | 注册→退出／登录→两份原创数据结构＋一份Python导入→章节→本地提取审核确认→同课栈融合→撤销／恢复→原成员定位代表及双源原文；他人课程404 |
| 同一账户恢复链 | 真实错答落库→ZIP导出→移出来源→digest变化、历史保留→备份预览／确认→双源恢复、错答仍1条、FK=0 |
| 浏览器B管理 | 提取／逐项审核／融合／指定撤销恢复／移出来源；关闭重开保留管理状态，未自动调用模型 |
| 浏览器原文 | 重复引文按保存的第二位置定位；补充Unicode字符、HTML样式文本安全展示；正文更改后重新打开明确不可用，无缓存成功 |
| 浏览器断网 | 主动停止本次自建8198进程→点击刷新→旧选中详情与快照保留且标为过期→重启同库→手动重试→错误和过期标记消失 |

| 撤销节点／迟到读／身份变更 | 控制器可控Promise回归：失效选中清除、跨课程／跨身份迟到数据拒绝、不同digest不拼接、最多重读一次 |
| 超量章节／来源 | 独立合成205章节＋63来源：目录第201章以后可达，来源50＋13分页，无横向溢出；不证明章节生成质量 |
