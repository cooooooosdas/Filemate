# 账号密码规则调整

按用户要求，注册和恢复码重设的新密码从最少15字符改为最少9字符，上限仍为128字符；同时包含英文字母与数字，大小写不限，符号可选，允许附加中文。明显重复及既有常见密码检查保留。登录继续验证已存摘要，已有15位以上或不含数字的旧密码无需修改。

前端注册/重设表单同步提示、错误焦点和规则，后端注册/恢复同步执行；不能仅修改页面提示或依赖前端检查。错误输入不产生账号、不消耗恢复码、不会注销现有会话。密码摘要、恢复码和Cookie机制不变，没有新增迁移，仍为alpha.4 / schema v25。
