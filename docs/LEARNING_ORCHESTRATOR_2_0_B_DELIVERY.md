## 使用合同

显式设置FILEMATE_ENABLE_LEARNING_ORCHESTRATOR=1后可使用新API，关闭值为0。先读snapshot并保留evidence_revision；preview提交同一scope、options及预期版本，confirm沿用原请求体并加confirmation_token、稳定request_key和confirmed=true。响应丢失先按request_key查询回执，不生成新键反复确认；undo同样先预览再确认。令牌有效期15分钟，单日最多100次新确认、同时最多100个有效未使用预览；重复回执不重复计数。

C级界面尚未实施，本级没有新增今日行动页面。现有业务入口继续执行真实任务；新接口及类型是下一阶段接入合同。
