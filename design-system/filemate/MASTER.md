# FileMate 设计系统

> 面向中国大学生与竞赛评委的桌面学习生产力产品：开放、自然、可信，像一张在日光下持续更新的学习工作台。

**设计旋钮：** 差异度 6 / 动效 4 / 密度 7

## 1. 设计原则

1. 先呈现“今天要学什么、为什么、做完得到什么”，再展示 AI 能力。
2. 每个 AI 结果必须能追溯到资料、题目或评测证据；不展示虚构准确率和趋势。
3. 桌面端以 1280–1440 px 为主，768 px 以下折叠侧栏，375 px 仍可完成上传、复习和确认。
4. 页面采用非对称 7:5 或 8:4 布局，避免连续三张等宽营销卡片。
5. 不使用紫粉渐变、漂浮装饰、表情图标、无限脉冲、过度毛玻璃或无依据的“AI 驱动”标签。

## 2. 视觉令牌

### 颜色

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 背景 | `#F5F8F4` | 带自然绿倾向的护眼画布 |
| 表面 | `#FFFFFF` | 主面板、表格、弹窗 |
| 侧栏 | `#EEF5EF` | 开放、安静的品牌区域 |
| 抬升表面 | `#EDF4EE` | 输入区、悬浮与分组 |
| 主文字 | `#183229` | 标题、正文 |
| 次文字 | `#4D655B` | 说明文字 |
| 弱文字 | `#6D8077` | 元数据 |
| 边框 | `#D7E3D9` | 分隔线 |
| 强调 | `#2F7D55` | 主按钮、选中态、焦点 |
| 成功 | `#2F7D55` | 已完成 |
| 警告 | `#9A651D` | 待确认 |
| 危险 | `#B44B4B` | 失败、删除 |

强调色只有自然森林绿一个色相。背景避免纯白铺满，绿色保持低饱和；成功、警告、危险仅用于状态，不用作品牌装饰。本阶段不提供暗色主题。

### 字体

```css
font-family: "MiSans", "HarmonyOS Sans SC", "Alibaba PuHuiTi 3",
  "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```

不远程加载字体；未获得字体文件和授权前使用系统回退。数字与代码使用 `ui-monospace, SFMono-Regular, Consolas, monospace`。

### 间距与形状

- 间距基线：4 / 8 / 12 / 16 / 24 / 32 / 48 px。
- 按钮与输入框圆角 10 px，面板 14 px，弹窗 16 px；不混用药丸形和超大圆角。
- 可点击区域最小 44×44 px。
- 阴影只用于弹窗和浮层；普通面板用 1 px 边框建立层级。

## 3. 图标与插图

- 产品内统一使用 `@element-plus/icons-vue`，常规 20 px、重点操作 24 px。
- 品牌标志允许使用独立 SVG；功能图标不手绘 SVG、不使用 Emoji。
- 若后续引入阿里巴巴 Iconfont，必须记录项目链接、授权和源文件版本，并按完整模块替换，不能与 Element Plus 在同一层级混用。
- 空状态使用图标、标题、解释和一个明确操作，不使用无意义 3D 插画。

## 4. 组件与交互

- 主按钮：实心强调色；同一区域最多一个主按钮。
- 次按钮：透明背景与边框；危险动作必须二次确认并说明可否恢复。
- 面板：默认无位移动画；悬停仅改变边框/背景，避免缩放导致布局跳动。
- 列表：文件名为主，时间/分类/状态为辅；状态同时使用文字，不能只靠颜色。
- AI 生成：完整提供等待、流式/进度、失败、重试、空结果与引用来源状态。
- 键盘：所有交互均支持 `:focus-visible`，焦点环 2 px 强调色、偏移 2 px。

## 5. 动效与层级

- 微交互 160 ms，面板切换 240 ms，弹窗 320 ms。
- 只动画 `opacity` 和 `transform`；信息表格不做交错飞入。
- 遵守 `prefers-reduced-motion`。
- z-index：内容 0、粘性页头 20、侧栏 30、下拉层 100、弹窗 200、通知 300。

## 6. 页面结构

- 应用壳：可折叠左侧栏 + 简洁页头 + 可滚动内容区。
- 首页：今日学习主任务（7）+ 学习闭环与资料动态（5），不做营销落地页。
- AI 工作区：资料上下文区 + 产物区；引用与原文定位固定可见。
- 题目/错题：题干与作答区（8）+ 证据、知识点、掌握度（4）。
- 模拟面试：视频/数字人舞台（7）+ 问题、评分量规和证据（5）。

## 7. 交付前检查

- [ ] 无 Emoji 功能图标、紫粉渐变、虚假指标和无意义装饰。
- [ ] 只使用一个图标家族、一个品牌强调色和一致圆角。
- [ ] 有 loading / empty / error / retry / disabled 状态。
- [ ] 对比度达到 WCAG AA，键盘焦点清晰，状态不只依赖颜色。
- [ ] 检查 375 / 768 / 1024 / 1440 px，无横向滚动。
- [ ] 动效尊重减少动画偏好，点击目标至少 44 px。
