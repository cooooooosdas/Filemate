======================================
    FileMate 便携启动器
======================================

【使用方法】
1. 将此文件夹复制到任何位置
2. 双击 "启动FileMate.bat"
3. 等待自动打开浏览器

【功能说明】
- 自动启动后端服务 (localhost:8000)
- 自动启动前端服务 (localhost:5173)
- 自动打开浏览器访问

【注意事项】
- 首次使用需要安装依赖 (pip install -r requirements.txt)
- 确保端口 8000 和 5173 未被占用
- 按 Ctrl+C 可停止服务

【技术栈】
- 前端: Vue3 + Vite + Element Plus
- 后端: FastAPI + Python
- AI: 云知声LLM API
