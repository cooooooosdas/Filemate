📡 完整数据流（端到端链路）

[感知层] FileParser.parse(path) ──▶ 提取 raw_text + metadata
                  ──▶ [理解层] Classifier.classify(text) ──▶ 分类标签 + 置信度
                  ──▶ [理解层] EntityExtractor.extract(text) ──▶ 课程名 / 截止时间 / 任务描述
                  ──▶ [理解层] Namer.generate(entities) ──▶ 建议文件名
                  ──▶ [执行层] Archiver / Scheduler ──▶ .ics 日程 + 归档目录规划
                  ──▶ [main.py] 打印最终结果 ──▶ ✅ 完成

5 个核心接口契约（联调时必须对齐）

FileParser.parse(path) → {raw_text: str, metadata: dict}
Classifier.classify(text, file_name) → {category: str, confidence: float}
EntityExtractor.extract(text, category) → {course_name, task_description, deadline, location}
Namer.generate(category, course_name, task, deadline) → str（建议文件名）
CalendarBuilder.build(events) → .ics 文件路径
接口协议文档：详见 filemate/docs/API_SPEC.md，所有模块必须遵守此规范，否则联调无法进行。

  • 每个 PR 必须包含对应的测试文件或测试用例更新

Git 工作流

  • commit 信息格式：feat(module): 做了什么 / fix(module): 修了什么 / test(module): 测试了什么
  • 每人每周至少 2 次有效 commit
  • 所有代码通过 PR 提交，胡希 review 后才能合并
  • 不允许直接 push 到 main，必须走 feature branch → PR → merge
